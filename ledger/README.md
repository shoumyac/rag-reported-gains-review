# Claim ledger

Every factual or numerical claim in the paper gets one row in `claims.csv` (added when the first draft exists):

| Column | Meaning |
|---|---|
| claim_id | Stable ID used in the manuscript source |
| text | The claim as written |
| type | number, citation, method, or interpretation |
| source | DOI of the cited work, or path to the script and output file |
| verified_by | Initials of the person who checked it against the source |
| date | Date checked |

Rules:
- Numbers are generated by script and pulled into the manuscript automatically. They are never typed by hand.
- A citation is accepted only if it appears in `references.bib` and passes `tools/check_citations.py`.
- A claim with no source is not allowed in the paper.
