# Protocol

The authoritative protocol is the OSF registration: https://doi.org/10.17605/OSF.IO/XGPCZ

Files here:
- `screening_instructions.md`: instructions for screeners (uploaded to the registration)
- `extraction_instructions.md`: extraction codebook (uploaded to the registration)
- `screening_pilot_instructions.md`: instructions for the 300-record calibration sample (screeners and annotators)
- `screening_discussion_instructions.md`: how to run the discussion session on the pilot disagreements
- `screening_round2_instructions.md`: instructions for the 100-record round 2 screening
- `screening_round2_discussion_instructions.md`: instructions for the authors' round 2 disagreement discussion
- `deviations_log.md`: every departure from the registered protocol, with date and reason

Do not edit the two instruction files in place after screening or extraction starts. If they must change, record the change in the deviations log and keep the old version in git history.
